# Security Policy

## Supported Versions
We currently provide security updates for the latest major release of `chronx`.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Because `chronx` operates as a global background daemon on users' computers, security is our absolute highest priority. 

If you discover a security vulnerability (such as a local privilege escalation or arbitrary file read), please **do not** open a public GitHub issue.

Instead, please email the maintainer directly. We will treat your report with the highest priority, acknowledge it within 24 hours, and aim to release a patched version immediately.
